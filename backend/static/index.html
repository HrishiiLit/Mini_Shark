About Mini-Shark

Mini-Shark: Network Protocol Analyzer & Packet Dissector

Built according to Wireshark specifications.

  • Engine E1: Multi-interface capture (Wi-Fi, Ethernet, Loopback, Promiscuous) and PCAP/PCAPNG parser
  • Engine E2: Multi-layer Protocol Dissection (Frame, Eth II, IPv4/v6, ARP, TCP, UDP, ICMP, DNS, HTTP, TLS, DHCP)
  • Engine E3: Display Filter Engine & Follow TCP Stream
  • Engine E4: Statistics, Conversations, Endpoints, I/O Graphs, and Expert Info Diagnostics

Self-contained implementation running locally on single laptop.
