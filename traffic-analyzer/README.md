# Mini Shark - Network Traffic Analyzer and Protocol Analysis System

**Team 07** · Guide: Pooja Shettar

## Overview

Mini Shark is a comprehensive network traffic analyzer and protocol analysis system. It consists of six engines working together to process, dissect, correlate, and query network traffic data.

## Architecture

The system is divided into six engines:

- **E1** - Packet & Frame Processing Engine: PCAP/PCAPNG loading, packet records
- **E2** - Protocol Dissection Engine: protocol identification, header parsing, tree
- **E3** - Flow & Traffic Analysis Engine: five-tuple flows, statistics
- **E4** - Traffic Query & Reporting Engine: storage, filter/query engine
